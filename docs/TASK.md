# Zames CRM · 开发 Task 清单

> 个人销售 CRM 客户项目管理工具。Mac 风、极简配色（1 彩色 + 灰度）、易用优先。
> 工作空间：`~/Desktop/Zames CRM/`

---

## 设计决策

### 极简配色

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#007AFF` | 激活态、主按钮、链接、进度条 |
| 主文字 | `#1D1D1F` | 标题、正文 |
| 次要文字 | `#86868B` | 说明、元信息 |
| 背景 | `#F5F5F7` | 页面底、侧边栏 |
| 卡片 | `#FFFFFF` | 内容卡片 |
| 边框 | `rgba(0,0,0,0.08)` | 分割线、描边 |
| 危险 | `#FF3B30` | 仅删除/危险操作 |

状态/优先级用「灰度圆点深浅 + 文字标签」，不用彩色徽章。

### 详情交互

客户卡片、项目卡片点击 → 右侧滑出 Drawer 详情面板，不跳页：
- 客户详情：基本信息 / 需求 / 关联项目 / 沟通记录（Tab 切换）
- 项目详情：基本信息 / 进展 / 里程碑 / 沟通记录
- 面板内可直接编辑、新增沟通记录
