# OneDay / 一日 — 变更日志

## v3.0 (2026-08-31) — OneDay 全新改版

### 方向变化
从个人 CRM 升级为 **AI 驱动的个人工作管理平台**。
核心逻辑：每日自由文本输入 → AI 解析 → 多模块结构化输出。
设计风格参考韩寒的「One 一个」：极简、黑白灰、大量留白、有温度。

### 新增模块
1. **开屏页（每日明信片）**：每日渐变壁纸 + 问候 + 每日一句 + 今日统计，抓睛卖点
2. **AI 对话**：主入口，模拟模式（规则匹配），自动提取待办/灵感/人名，鼓励型回应
3. **待办（To Do）**：增删改查、完成标记、优先级、AI 自动提取
4. **重要事件**：通用项目/事件跟进，阶段、优先级、金额、截止日、下一步行动
5. **灵感**：随手记录，AI 自动提取
6. **运动**：每日打卡、本周/本月/累计统计、未打卡提醒
7. **朋友**：AI 草记人名 + 用户完善 + 关系图谱（力导向图）
8. **设置**：个人信息、定时提醒、AI 配置、数据管理

### 后端能力
- 通用 CRUD 框架（8个模块统一 API）
- 定时任务：早间问候（默认7:30）、晚间总结（默认22:00）、运动提醒（默认20:00）
- macOS 系统通知
- AI 模拟：规则匹配提取信息 + 鼓励型对话
- 每日壁纸：渐变背景（预留 AI 生成接口）

### 数据迁移
- 旧 CRM 3个项目已迁移（stage 字段中英转换）
- 旧 CRM 2个待办已保留
- 数据存储：JSON（data/目录），统一管理

### 已知限制
- AI 为模拟模式（规则匹配），提取精度有限，配置 API Key 后启用真实大模型
- 每日壁纸为静态渐变，AI 生成壁纸待接入图片生成 API
- 系统日历对接未实现（现阶段不连系统）
- 语音输入未实现（建议用 Typeplus 语音转文字后粘贴）
