## 已确认待做（按优先级排序）

### P0 — 核心能力升级
1. **AI 真实大模型接入**
   - 接入 DeepSeek 或豆包 API（用户购买 API Key 后）
   - 替换当前的规则匹配模拟模式
   - 提升对话质量和信息提取精度
   - 位置：设置页面配置 API Key

2. **AI 生成专属每日寄语** ⭐ 用户明确要求
   - 结合用户当天状态（心情、待办、项目进展、运动情况）
   - 生成只属于用户的一句寄语
   - 例：用户今天累了 → "辛苦了，今天可以慢一点"
   - 例：用户今天开心 → "今天的状态很好，继续保持"
   - 替换当前的固定10句轮换

3. **结合节气/节日的寄语** ⭐ 用户明确要求
   - 二十四节气（立春、雨水、惊蛰、春分...冬至）
   - 传统节日（春节、元宵、清明、端午、中秋、重阳等）
   - 用户生日、纪念日等个人特殊日子
   - 例：冬至 → "冬至大如年，人间小团圆"
   - 例：生日 → "生日快乐，新的一岁"

### P1 — 开屏页升级
4. **AI 生成个性化每日壁纸** ⭐ 核心亮点
   - 输入素材：用户数据（心情/待办/项目/运动）+ 节气/节日 + 天气 + 季节
   - 调用 AI 图片生成 API（文心一格/通义万相等）
   - 每个用户每天生成独一无二的壁纸
   - 一天只生成一次，缓存到本地
   - 宣传口径："每个人有独一无二的当日一张图"

5. **壁纸风格自定义**
   - 用户可选择偏好风格（摄影/插画/抽象/极简）
   - 用户可选择色调偏好（暖色调/冷色调/黑白）
   - 位置：设置页面

### P2 — 功能完善
6. **系统日历对接**
   - 待办有具体时间时自动添加到系统日历（macOS Calendar）
   - 现阶段不连系统，后续实现
   - 技术：AppleScript / EventKit / .ics 导出

7. **每日想法模块**
   - 每天晚上集中输入当日感想/做了什么/没做什么
   - AI 分析并提取待办/项目/灵感
   - （当前 AI 对话已部分覆盖，可独立成模块）

8. **精力管理**
   - AI 从每日输入中自动分析精力状态
   - 不单独做模块，作为评估维度存在
   - 开屏页或设置中展示精力趋势

### P3 — 社交化（后期）
9. **壁纸分享功能**
   - 把当日壁纸+寄语生成一张可分享的图片
   - 分享到微信/微博/小红书等社交平台
   - 宣传口径："你的一天，值得被看见"

10. **好友系统与点赞**
    - 用户注册/登录（需要云服务器）
    - 好友关系链
    - 好友间可以看到对方的当日壁纸并点赞
    - 宣传口径："每个人有独一无二的当日一张图，还能让好友点赞"

### P4 — 多端与部署
11. **手机端适配 / PWA**
    - 响应式布局适配手机
    - PWA 加到主屏幕，像 App 一样使用
    - 局域网访问（同一 WiFi 下手机访问电脑 IP）

12. **云服务器部署**
    - 部署到云服务器，随时随地访问
    - 成本：约 100-300元/年（新用户优惠）
    - 数据安全：HTTPS + 强密码 + 定期备份

13. **内网穿透**
    - 用 ngrok/frp 把本地服务暴露到公网
    - 手机用 4G/5G 也能访问
    - （云服务器的替代方案）

## 技术债务 / 已知限制
- [ ] AI 为模拟模式，提取精度有限
- [ ] 每日壁纸为静态 demo 图
- [ ] 系统日历未对接
- [ ] 语音输入未实现（建议用 Typeplus 语音转文字后粘贴）
- [ ] 数据存储为本地 JSON，未加密
- [ ] 无数据导出/备份功能（手动复制 data/ 目录）

## 设计原则
- 「One 一个」风格：极简、黑白灰、大量留白、有温度
- AI 是触手：拟人化沟通 + 无声息数据捕捉
- 工具是骨架：结构化存储、展现、分析
- 输入人性化，输出工具化
- 少即是多，不做复杂交互
