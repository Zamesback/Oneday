## 一、项目一句话介绍

**OneDay / 一日** — AI 驱动的个人生活管理平台。不用打字，只要闲聊，AI 帮你记录一切，每天生成一张专属于你的卡片。

**English:** OneDay is an AI-powered personal life management platform. No typing, just chat — AI records everything for you, and generates a unique card every day.

---

## 二、项目详细描述

### 2.1 产品定位

OneDay 是一个面向个人的 AI 生活助手和管理工具。核心理念是**"不用打字，只要闲聊"**——用户不需要手动录入任何数据，每天花 5-10 分钟跟 AI 说说话，它会自动帮你整理待办、项目、灵感、朋友、运动等信息，并且在每个清晨为你生成一张专属于你的开屏卡片，用你自己的方式开启新的一天。

### 2.2 产品起源

这个产品源于一个简单的个人习惯：每天睡前跟 AI 复盘当天发生的一切。

从 ChatGPT 时代开始，我就尝试用 AI 记录生活。后来在宁德时代工作压力最大的日子里，这个习惯变成了每日复盘——"今天真是糟糕的一天"或者"今天完成了好多事"。久而久之发现：**你要能表达就要想得透，想得透才能说得出，说得出它才能记得住**——而记得住，就衍生出了 OneDay 的一切模块。

从最初的"伴生"到"龙虾"，工具在变，但那个"每天睡前跟 AI 说说话"的核心一直没变，最终成为了 OneDay。

### 2.3 核心亮点

#### 亮点一：不用打字，只要闲聊
一切通过和 AI 生活助手对话完成。它会自动帮你整理待办、项目、灵感、运动、朋友，你只需要说。

#### 亮点二：每日专属卡片
AI 结合你的状态、待办、节气、天气，每天生成一张独一无二的卡片。一年 365 天，你就有 365 张专属于你的卡片，记录你度过的每一天。

#### 亮点三：Plog — 把日子录成播客
**Plog = Podcast as a Log**。每一次闲聊，AI 都会帮你收集灵感。从灵感主题到节目大纲，一键录制，快速生成一期属于你的播客，把你的生活用语音的方式记录下来。

#### 亮点四：朋友图谱
AI 在闲聊中自动捕捉你提到的人，记录身份、关系和互动。被提及越多的人，在图谱里的节点越大——让你直观看到谁在你生活里最重要。

## 三、功能模块

| 模块 | 说明 |
|------|------|
| 🌅 开屏页 | 每日专属壁纸 + 个性化寄语，开启新的一天 |
| ✅ 待办清单 | 日历视图 + 待办列表，AI 自动从聊天中提取 |
| 📋 重要事件 | 项目/重要事件跟进，状态和优先级管理 |
| 🎙 Plog 灵感 | 灵感收集 → AI 生成大纲 → 一键录制播客 |
| 👥 朋友图谱 | 关系网络可视化，节点大小 = 提及频率 |
| 🃏 卡片集 | 日历式卡片排布，一年 365 张专属卡片 |
| 💬 AI 对话 | 声波式语音交互界面，无打字纯对话 |
| ⚙️ 设置 | 深色/亮色模式切换，个性化配置 |

## 四、技术栈

- **前端**：原生 HTML + CSS + JavaScript（单页应用，无框架依赖）
- **后端**：Python Flask（轻量本地服务，端口 8765）
- **数据存储**：JSON 文件（本地存储，无需数据库）
- **AI 能力**：支持接入 DeepSeek / 豆包等大模型 API
- **设计风格**：Nothing × One 混搭风格，黑白红三原色

---

## 五、设计风格

### 5.1 视觉风格
- **配色**：黑白红三原色（#000 / #FFF / #FF3B30）
- **中文字体**：Noto Serif SC 衬线体（温暖、有质感）
- **英文字体**：Space Mono 等宽体（电子感、个性）
- **整体调性**：年轻、个性、有态度，同时保持简洁和温暖

### 5.2 设计理念
- 输入端更人性化（纯语音对话，无打字）
- 数据展示端工具化（清晰的模块和可视化）
- 每日开屏页是产品的"抓睛卖点"——千人千面，独一无二
